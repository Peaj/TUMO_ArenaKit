🏅Challenge-Karten

Ausschneiden und auf die Tische legen. 🟢 einstellen und platzieren, 🟡 Bausteine verbinden, 🔴 eigene Scripts.

🟢 Start

🌙Mondlandung

Mach dein Level zum Mondlevel. Wie verändert sich das Spiel?

So geht's: Level Rules > Gravity = 0.3
🟢 Start

🦘Superspringer

Dein Spieler kann in der Luft noch zweimal springen.

So geht's: DeinNamePlayer > Extra Jumps = 2
🟢 Start

⛸️Eisbahn

Alle rutschen! Baue eine Arena, in der das lustig ist.

So geht's: DeinNamePlayer > Braking = 0
🟢 Start

Schrot-Party

Baue eine Waffe, die 12 Kugeln auf einmal schießt.

So geht's: Prefab Variant der Shotgun > Projectiles Per Shot = 12, Spread = 60
🟢 Start

Kistenburg

Baue eine Burg aus Kisten und Mauern, die man erst wegschießen muss.

So geht's: Crate und BrickWall stapeln. Bei Breakable > Health kannst du einstellen, wie viel sie aushalten.
🟢 Start

Risiko!

Die stärkste Waffe liegt an der gefährlichsten Stelle deiner Arena.

So geht's: Pickup_Bazooka zwischen Stacheln oder über Lava legen
🟢 Start

Rasende Säge

Lass eine Säge einen langen Weg fahren, schnell oder langsam.

So geht's: Saw > Mover > Offset (wohin) und Speed (wie schnell)
🟢 Start

Raketenfeder

Eine Sprungfeder, die dich bis an die Decke schießt.

So geht's: JumpPad > ForcePush > Speed = 25
🟡 Profi

Hebel-Tür

Ein Hebel öffnet und schließt eine Tür.

Lever > On Turned On → Door > Open
Lever > On Turned Off → Door > Close
🟡 Profi

Schlüsselrätsel

Versteck einen Schlüssel. Er öffnet den Weg zur besten Waffe.

Key > TriggerZone > On Enter → LockBlock > Open
🟡 Profi

Münz-Tür

Erst wenn 3 Münzen gesammelt sind, geht die Tür auf.

Jede Coin > TriggerZone > On Enter → Counter > Add
Counter (Target 3) > On Reached → Door > Open
🟡 Profi

Bombenregen

Alle paar Sekunden fällt TNT vom Himmel.

Spawner oben in die Arena: Prefabs = TNTBlock, Interval = 3, Max Alive = 5, Random Offset x = 10
🟡 Profi

⏰Zeitbombe

Nach 20 Sekunden explodiert eine Kiste in der Mitte.

Crate > Add Component > Explosive
Timer (20 s) > On Finished → Explosive > Explode
🟡 Profi

Fallen-Knopf

Wer auf den Knopf drückt, wird über die Lava gebeamt.

Leeres Objekt als Ziel, Teleporter mit Target = Ziel
Button > On Turned On → Teleporter > Teleport
🟡 Profi

Aufzug auf Knopfdruck

Der Aufzug fährt nur, wenn jemand den Knopf drückt.

Elevator > Mover > Move Automatically aus
Button > On Turned On → Mover > MoveToEnd
On Turned Off → MoveToStart
🟡 Profi

Geheimgang

Ein versteckter Hebel lässt eine Mauer verschwinden.

BrickWall > Add Component > Disappear
Lever > On Turned On → Disappear > Hide
🔴 Code

🧑‍💻Dein erstes Script

Eine TriggerZone, die dich höher springen lässt. Rechtsklick in deinem Ordner > Create > Scripting > MonoBehaviour Script, Name beginnt mit deinem Namen.

using ArenaKit;
using UnityEngine;

public class LenaSuperJump : MonoBehaviour
{
    public float ExtraHeight = 3f;

    // TriggerZone > On Enter → LenaSuperJump > Apply
    public void Apply()
    {
        Character player = TriggeredBy.Character;
        if (player != null)
            player.JumpHeight += ExtraHeight;
    }
}
🔴 Code

👟Turbo-Schuhe

Wie „Dein erstes Script“, aber der Spieler wird schneller.

Tipp: player.MaxSpeed += 5f;
Lege das Script auf einen Coin, dann ist es ein Power-up.
🔴 Code

🚀Schleudersitz

Wer in die Zone läuft, wird senkrecht nach oben geschossen.

Tipp: player.Body.linearVelocity = new Vector2(0f, 25f);
Was passiert mit 0 statt 25? Und mit -25?
🔴 Code

⚖️Ausgleich

Wer gerade hinten liegt, bekommt einen Extrapunkt.

Tipp: LevelRules.Current.GetPoints(1) liefert die Punkte von Spieler 1, LevelRules.Current.AddPoint(2) gibt Spieler 2 einen Punkt.
